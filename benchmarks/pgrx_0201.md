# pgrx 0.20.1 Upgrade and Runtime Optimization Benchmark

Started: 2026-11-23T16:40:58+00:00 (PG18.7) and 2026-11-23T16:41:51+00:00 (PG19.0).

20,000 documents; 2,000 queries (PG18); 3 fresh rotated rounds per variant.

All variants use the same PostgreSQL server, compiler, dictionaries, and release
flags (fat LTO, single codegen unit), with JIT and PostgreSQL parallel query
disabled and durability enabled (`fsync`, `synchronous_commit`,
`full_page_writes`). Raw JSON/logs remain outside the repository.

- `pgrx0200_main`: `origin/main` (`300fcb1`) built with `pgrx` / `cargo-pgrx`
  0.20.0 and Rust 1.99.1.
- `pgrx0201_after`: upgraded to `pgrx` / `cargo-pgrx` 0.20.1 (removing unused
  `serde_json`), plus arena-backed `CharDictionary` and flat `WordTrie`,
  zero-copy SPI dictionary loading, delta-only suffix overlays with direct
  syscache relation lookup, per-query `fn_extra` direct-cast caching with
  syscache invalidation, streaming borrowed `text[]` tokenizer slices, and flat
  ASCII tries with zero-alloc ASCII fast paths in pattern parsers.

Extension version remains `0.0.9` with identical SQL catalog and migration bytes.
All conversion checksums, ICU pronunciation gold checks, and full ranked Top-K
scored hits matched across every round.

## Attribution and Verification

- The runtime and memory reductions come primarily from the compact dictionary
  and trie layouts, delta-only suffix overlays with syscache relation checks,
  `fn_extra` cast caching, and flat ASCII parser tries, not from the patch-level
  `pgrx` 0.20.0 -> 0.20.1 upgrade alone.
- Local validation passed on ARM64 Linux:
  - `cargo fmt --check`, 39 Rust unit tests, `benchmark_pinyin_regex_phrase` check,
    24 dictionary generator tests, and `test_dictionary_accuracy.py`.
  - PG18.7 + `pg_search 0.27.0`: 49/49 `pgrx test`, 214/214 Python tests
    (including `v0.0.8 -> 0.0.9` upgrade and cached-cast ACL/DDL/NULL-cast
    checks), and 1,652/1,652 pgTAP assertions.
  - PG15.20, PG16.16, PG17.12, PG19.0: built all five PG15-19 DEB packages with
    zero SQL catalog drift, passed runtime/upgrade Python checks and 95/95 core
    pgTAP assertions on each major, plus 49/49 `pgrx test` on PG19.0.
